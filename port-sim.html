Common Port Information

80: HTTP Web Service
443: HTTPS Secure Web Service
21: FTP File Transfer (High Risk)
25: SMTP Email Service

Observation: Universities usually open more ports to provide public services. Companies keep fewer open ports to reduce security risks.
