CCNA revision topics

Use these groups to plan study sessions alongside the interactive tools.

Network fundamentals Topologies, devices, media, protocols, and reliable networks.
Switching and Ethernet Frames, MAC addresses, MAC tables, VLAN concepts, and forwarding.
Routing and IP connectivity IPv4/IPv6 packets, routing decisions, interfaces, and default gateways.
Addressing and subnetting Binary, CIDR, IPv4/IPv6 addressing, subnetting, and VLSM.
Network services ARP, Neighbor Discovery, ICMP, DNS, DHCP, HTTP, and transport ports.
Security and operations IOS commands, device hardening, threats, mitigations, and troubleshooting.

Practice prompts

Use these as written exercises before opening a Packet Tracer activity.

Subnetting Find the network, broadcast, and usable host range for 10.20.30.77/27.
Switching Explain how a switch learns a MAC address and what happens when the destination is unknown.
Routing Explain why a host needs a default gateway to reach a different subnet.
Troubleshooting Plan a sequence using interface status, IP configuration, ping, and traceroute to diagnose a connectivity issue.
