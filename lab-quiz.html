1. Which layer does a switch operate on?




Explanation:
Switches operate at Layer 2 (Data Link Layer) of the OSI model. They use MAC addresses to forward frames within a local area network.

2. What is the main function of a router?




Explanation:
Routers connect different networks together using IP addresses at Layer 3 (Network Layer). They determine the best path for data to travel between networks.

3. What does CMOS battery store?




Explanation:
The CMOS battery powers the BIOS configuration and maintains system time even when the computer is powered off.

4. Which RAID level provides mirroring?




Explanation:
RAID 1 provides data mirroring, which means data is duplicated on two drives for redundancy and protection against single drive failure.

5. What tool protects hardware from ESD?




Explanation:
An anti-static wrist strap safely grounds you to prevent Electrostatic Discharge (ESD), which can damage sensitive computer components.

6. What information does DHCP assign automatically?




Explanation:
DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses to devices on a network, reducing manual configuration.

7. Minimum number of hard drives required for RAID 5?




Explanation:
RAID 5 requires a minimum of 3 hard drives to stripe data with parity across multiple drives for fault tolerance.

8. Why do technicians use port scanning?




Explanation:
Port scanning is used to identify open ports on a system for security auditing and checking for potential vulnerabilities.

9. UTP cable stands for?




Explanation:
UTP (Unshielded Twisted Pair) is a common networking cable type used in Ethernet connections without additional shielding.

10. What can protect computer against power surges?




Explanation:
A surge protector detects and stops sudden voltage spikes from reaching your computer, protecting against power surges.
