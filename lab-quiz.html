Networking Technology Quiz

1. Which layer does a switch operate on?




Explanation:
Switches operate at Layer 2 (Data Link Layer) of the OSI model. They use MAC addresses to forward frames within a local area network.

2. What is the main function of a router?




Explanation:
Routers connect different networks together using IP addresses at Layer 3 (Network Layer). They determine the best path for data to travel between networks.

3. Which RAID level provides mirroring?




Explanation:
RAID 1 provides data mirroring, which means data is duplicated on two drives for redundancy and protection against single drive failure.

4. Minimum number of hard drives required for RAID 5?




Explanation:
RAID 5 requires a minimum of 3 hard drives to stripe data with parity across multiple drives for fault tolerance.

5. What information does DHCP assign automatically?




Explanation:
DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses to devices on a network, reducing manual configuration.

6. How do you enter privileged EXEC mode on a Cisco device in Packet Tracer?




Explanation:
To enter privileged EXEC mode on a Cisco device, use the 'enable' command. This gives you access to more powerful configuration options. Once in privileged mode, you can use 'configure terminal' to enter global configuration mode.

7. What is subnetting used for in networking?




Explanation:
Subnetting divides a large IP network into smaller, manageable sub-networks. This improves network efficiency, reduces broadcast traffic, and enhances security by logically separating network segments.

8. For a Class C network (192.168.1.0/24), what is the subnet mask?




Explanation:
A Class C network with /24 CIDR notation means the first 24 bits are the network portion and the remaining 8 bits are for hosts. The subnet mask is 255.255.255.0, which provides 254 usable host addresses (0 and 255 are reserved).

9. Which command disables DNS lookup on a Cisco router?




Explanation:
In Cisco IOS, the command 'no ip domain-lookup' disables DNS lookup on the router. This is useful during configuration to prevent the router from attempting to resolve unrecognized commands as hostnames, which can cause delays.

10. UTP cable stands for?




Explanation:
UTP (Unshielded Twisted Pair) is a common networking cable type used in Ethernet connections without additional shielding. It's widely used in office and home networks due to its cost-effectiveness.

Computer Maintenance Quiz

1. What does CMOS battery store?




Explanation:
The CMOS battery powers the BIOS configuration and maintains system time even when the computer is powered off. When the CMOS battery dies, you may see errors during boot or incorrect system time.

2. What tool protects hardware from ESD (Electrostatic Discharge)?




Explanation:
An anti-static wrist strap safely grounds you to prevent Electrostatic Discharge (ESD), which can damage sensitive computer components like RAM, motherboards, and graphics cards. It's essential when working inside a computer case.

3. What can protect a computer against power surges?




Explanation:
A surge protector detects and stops sudden voltage spikes from reaching your computer, protecting the power supply and internal components from damage caused by power surges from lightning or electrical faults.

4. Which of the following is a best practice when upgrading RAM?




Explanation:
Before upgrading RAM, you should always ground yourself with an anti-static strap to prevent ESD damage. Always power off the computer completely and unplug it before opening the case. Mix RAM brands is acceptable if the speed and type match.

5. Which of the following display standards is known as 4K?




Explanation:
4K resolution, also known as Ultra HD (UHD), is 3840 x 2160 pixels. It provides four times the pixel count of Full HD (1080p), resulting in much sharper and more detailed images. 4K displays are increasingly common in modern monitors, TVs, and laptops.

6. When disposing of old computer equipment, which is an environmentally responsible approach?




Explanation:
Old computer equipment contains hazardous materials like lead, mercury, and cadmium. The most environmentally responsible approach is to donate working equipment to schools or nonprofits, or send it to certified e-waste recycling facilities that properly handle toxic components and recover valuable materials.

7. What is the first step when upgrading a hard drive?




Explanation:
Before any hardware upgrade, especially storage devices, you should always back up your data to prevent loss. Then power off the computer completely, unplug it, and ground yourself before opening the case or handling components.

8. How often should you clean the interior of a desktop computer to prevent overheating?




Explanation:
Dust accumulation inside a computer reduces airflow and causes components to overheat. Regular cleaning every 6-12 months (more frequently in dusty environments) is essential for maintaining optimal performance and preventing hardware failure. Use compressed air to gently blow out dust from fans and heat sinks.

9. What should be done before replacing the graphics card (GPU)?




Explanation:
Before replacing a GPU, check that your power supply has enough wattage for the new card. Uninstall old GPU drivers in safe mode to prevent conflicts. Always power off and unplug the computer before opening the case. After installation, install new drivers for proper functionality.

10. What are the environmental concerns with improper computer disposal?




Explanation:
Computers contain toxic substances including lead (in solder), mercury (in displays), and cadmium (in batteries). When disposed of improperly in landfills, these materials leach into soil and groundwater, causing environmental and health hazards. E-waste recycling programs properly extract and handle these hazardous materials.
