Project Introduction

This website is a fully compliant educational tool for polytechnic students. There is NO real port scanning function. All port data are pre-simulated local data, which will not send any requests to external websites.

It covers core networking knowledge: switch MAC table, ARP operation, TCP/UDP ports, IP subnetting, duplex mode and frame forwarding modes.

Core Functions

  • Virtual Port Simulator: Compare port exposure data of university & corporate organizations with charts
  • Subnet Calculator: Automatically calculate network ID, broadcast address and usable host quantity
  • AI Chatbot: Answer questions only related to computer network topics
  • Lab Quiz: Auto-marked multiple-choice questions about ARP and switch fundamentals
